1. Short_Straddle_BankNifty
----------------------------------------------------------------
Introduction   : A trading bot that trades in the stock market.
                 Retrieves real-time data from Alice Blue brokerage

                 automated trades based on model decisions.
Technology     : Python, Alice Blue API, Jupyter Notebook
Main Domain    : Algorithmic Trading / Finance

2. F-and-O-Prediction-Stock-Market-
----------------------------------------------------------------
Introduction   : Models Implied Volatility Surface dynamics using

                 EDA, dimension reduction, and ML techniques to
                 represent matrix-valued stochastic processes.
Technology     : Python, Machine Learning, Jupyter Notebook
Main Domain    : Financial Forecasting / Quantitative Finance
